📊 OFFICIAL CNCF KCNA DOMAIN DISTRIBUTION & WEIGHTAGE
--------------------------------------------------------------------
1. Kubernetes Fundamentals (46%)
   ├── Kubernetes Architecture (Control Plane & Worker Node components)
   ├── Kubernetes API & Resources (Pods, Deployments, Services, ConfigMaps, Secrets, PV/PVC)
   ├── Containers & Container Security (OCI specs, Dockerfiles, rootless containers)
   └── Workload Controllers (DaemonSets, StatefulSets, Jobs, CronJobs, CRDs)

2. Container Orchestration (22%)
   ├── Container Orchestration Fundamentals (Scheduling, Auto-scaling, Self-healing)
   ├── Container Runtime Standards (CRI, containerd, CRI-O, runc)
   ├── Networking Standards (CNI, Calico, Flannel, Cilium, NetworkPolicies)
   └── Storage Standards (CSI, StorageClass, PV AccessModes: RWO, ROX, RWX)

3. Cloud Native Architecture (16%)
   ├── Cloud Native Principles (CNCF Charter, 12-Factor App methodology)
   ├── Microservices vs. Monolith vs. Serverless / FaaS (Knative, OpenFaaS)
   ├── Service Mesh (Istio, Linkerd, Envoy sidecar proxies, mTLS, Traffic splitting)
   └── CNCF Ecosystem & Landscape (Graduated, Incubating, Sandbox projects)

4. Cloud Native Observability (8%)
   ├── Telemetry & Metrics (Prometheus metric types: Counter, Gauge, Histogram, Summary)
   ├── Logging (Fluentd, Fluent Bit, Loki, stdout/stderr aggregation)
   └── Distributed Tracing (OpenTelemetry, Jaeger, Zipkin, Trace/Span IDs)

5. Cloud Native Application Delivery (8%)
   ├── CI/CD Pipelines (Tekton, GitHub Actions, Jenkins)
   ├── GitOps (ArgoCD, Flux, Continuous Reconciliation, Drift Detection)
   └── Helm & Package Management (Charts, Chart.yaml, values.yaml, Templates)
